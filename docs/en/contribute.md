The project lives on GitHub: [pokemonmuia/pokemon-muia](https://github.com/pokemonmuia/pokemon-muia).

1. Install [GitHub Desktop](https://desktop.github.com/download/) and clone the repository.
2. Before you start: **Fetch origin**, then **Pull origin**.
3. Work in the game and save with Ctrl+S.
4. Write the **Summary**, **Commit**, then **Push origin**.

> **Heads up:** if two people edit the **same map** at the same time, one of the changes is lost. Agree beforehand on who works on what.

If you change anything in the `PBS` folder (Pokémon, trainers, items...), start the game from RPG Maker with **F12** to recompile the data, then commit the changed `.dat` files in `Data` too.
