# Pokémon Muia – Caput Mundi

The first Pokémon fan game set in Muia. You land at the Molo dell'Illusion on the green dolphin, wander the town, pick a side and challenge eight gym leaders.

Built with Pokémon Essentials v21.1 and RPG Maker XP by the **Cypress Hill Crew**. The game text is in Italian; an English translation is planned.
